# Как читать эту папку

- `dashboard.html` — открывается сам в начале сборки; можно и двойным кликом.
  Этапы, прогресс, время, что осталось. Обновляется сам, пока сборка идёт.
  `index.html` рядом — тот же файл под другим именем. Отдельно его открывать не нужно.
- `<дата>-<проект>/` — папка одной сборки. Дата в имени — день, когда сборка началась.
  Суффикс `--wip` значит «ещё делается»; когда сборка сдана, суффикс снимается. Внутри:
  - `<дата>-brief.md` — твоя изначальная задача, слово в слово, и «Дополнения».
  - `manifest.md` — список требований и что с каждым стало.
  - `spec.md` — спецификация.
  - `tickets/` — таски, на которые разбита сборка.

Если сборка прервалась — скажи агенту «продолжи автопилот».
