## Что должно заработать
Первый экран главной: фото кирпичного дома `Референсы/hero-фото/hero-дом-кирпич.png` (WebP в `public/`) и два принципиально разных варианта Hero с переключателем «1 · 2» внизу справа, `?hero=2`, запоминанием выбора. Шапка в варианте 1 прозрачная поверх фото и белеет при скролле; в варианте 2 белая. Scroll-анимация: фото scale 1.08 → 1.0, текст вверх + fade. Тексты Hero — из текущего кода, без изменений.

## Критерии приёмки
- [ ] Фото: PNG → WebP (≈ 2000px, качество ~80; конвертер — `sharp` из `node_modules`, если он есть, иначе Python/Pillow; ничего не устанавливать), `next/image` с `priority`; крыша и цоколь видны на 1440×900 и 1920×1080; на мобильном дом целиком
- [ ] Вариант 1 «Обложка»: 100svh (мин. 640), белый H1 64–72 (моб. 40–44), пункты `heroFeatures`, одна белая кнопка «Рассчитать стоимость» + текстовая ссылка «Смотреть проекты», градиент сверху и слева и приглушённый низ, AA-контраст
- [ ] Вариант 2 «Редакторский»: светлая композиция по описанию в спецификации; те же тексты и то же фото
- [ ] `<Hero />` остаётся тем же экспортом; секция сохраняет `id="hero"`
- [ ] Шапка: в варианте 1 прозрачная, белая после скролла с линией `--line`; меню, телефон, мессенджеры, бургер работают; читается над фото; на остальных страницах белая
- [ ] Scroll-анимация без прыжков; при `prefers-reduced-motion` отключена
- [ ] Переключатель: плавающий, доступный (aria), `?hero=`, `localStorage` в try/catch, по умолчанию 1; без hydration mismatch; на `<html>` ставится `data-hero`
- [ ] Проверено в браузере (десктоп и 375/390); `npm run build` и `npm run lint` проходят
