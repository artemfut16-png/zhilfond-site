# 07 — Единый радиус 12px по всему сайту

**Требования:** G04
**Blocked by:** 01
**Зона:** `src/app/globals.css` · `src/components/ui/` · `src/components/sections/` (кроме `hero*.tsx`) · `src/components/catalog/` · `src/components/*.tsx` (кроме `site-header.tsx`)
**Волна:** 3
**Status:** ready

## Что должно заработать
Все прямоугольные элементы (кнопки, карточки, фото/превью, поля ввода, плитки выбора, аккордеон, диалоги, чипы, карта, формы, футер-блоки) имеют один радиус 12px. Нет ни квадратных (0), ни 8/15/16/24. Круглые элементы (бейджи-кружки, аватары, точки таймлайна) остаются кругами (`rounded-full`).

## Из брифа, дословно
> «сделай округление всех элементов одного формата, не должно быть что что-то квадратное прям с 0 окруеглением, а что-то с округлением 15. Фокус на округление 12»

## Критерии приёмки
- [ ] Единый токен: `--radius: 12px` (+ `--radius-card`, `--radius-btn`, `--radius-pill` → 12px, где pill не круг); `Button` без `rounded-none`, `rounded-lg`/`rounded-(--radius)` через токен
- [ ] `grep` по зоне: нет `rounded-none`, `rounded-sm/md/xl/2xl/3xl`, `rounded-[…]` с другими значениями, кроме `rounded-full` для кругов
- [ ] Картинки внутри скруглённых карточек обрезаются по радиусу (`overflow-hidden`)
- [ ] Страницы каталога/privacy получают тот же радиус автоматически
- [ ] Ничего, кроме радиусов, не менять (тексты, раскладки, цвета)
- [ ] `tsc`, `eslint` по изменённым файлам чисто
